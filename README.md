# Ligo — Cole demo

You’re **Cole**, running **Georgetown Program Board** on Ligo.

Open it: **[ligo-cole-demo.vercel.app](https://ligo-cole-demo.vercel.app)**

That’s it — no login, no switching accounts. Just click around.

---

## What to do (like 2 minutes)

1. Hit **Manage** at the top  
   → you’re in GPB ops (events, members, invites)

2. Tap **Invite members**  
   → this is “get people on Ligo,” not a party guest list

3. Hit **+ Create** → **Autofill Kickoff** → publish as **Members Only**  
   → then open **Group chat** on that event (it’s for *this* event, not the whole club GroupMe)

4. Create again → **Autofill Breakfast** → publish to **Georgetown**  
   → flip to **Explore** — Breakfast should be on the campus feed

Kickoff stays inside the club. Breakfast goes campus-wide. That’s the whole point.

---

## Other tabs (optional)

- **Explore** — what’s public on campus  
- **My Events** — your stuff  
- **Clubs** → GPB → Chat / Events / People if you wanna poke around the member side
