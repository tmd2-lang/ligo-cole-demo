## First thing you see: Pass / I’m In

When the demo opens, you’ll get **invite cards** stacked on top of Events.

This is the fast RSVP for private / invite-only stuff:

| Button | What it means |
|--------|----------------|
| **I’m In** | You’re going. Saves your RSVP. Event lands in **My Events**. |
| **Pass** | You’re out. Card goes away. |

You can also **tap the card** (or the flyer) to open the full event page first, then decide.

Work through a couple cards so you feel it — then you’ll land in the main Events tabs.

---

## The four tabs

Once the invites are done (or dismissed), you’ll see four tabs at the top:

**Explore · My Events · Clubs · Manage**

### Explore
Campus feed — public Georgetown events ordered so you can browse what’s happening.

**Try this:**
1. Scroll **This Week** and other sections.
2. Open an event (ex. something on campus).
3. Read the flyer / details.
4. RSVP from the bottom of the event page if you want.

Explore = “what’s open to campus.” Members-only club stuff will **not** show here.

### My Events
Your personal hub for everything on your calendar side of Ligo:

- events you said **I’m In** / Going / Maybe to  
- invites you haven’t answered yet  
- stuff you’re **hosting** as GPB admin  

**Try this:** after you I’m In on an invite, flip to **My Events** and find it.

### Clubs
If you’re in an org, this is the **club home** — not the whole campus.

You’re in **Georgetown Program Board**. Tap it.

You’ll get a short welcome, then:

| Section | What it is |
|---------|------------|
| **Chat** | Whole-club chat (ops / banter) — **not** the same as an event group chat |
| **Events** | GPB events for members, plus campus ones GPB is also hosting |
| **People** | Roster / who’s in the org |

Because you’re an **admin**, you’ll also see **Open event ops** — that jumps you into organizer tools without using the Manage tab.

**Try this:** Clubs → GPB → Events → open a members-only event → open **Event group chat** if it’s there. That’s the thread for *that event*, separate from club Chat.

### Manage
Your **admin ops** for GPB. This is the organizer product.

Tap **Manage** → short splash (“Running the board · GPB”) → Event ops:

| Area | What to do |
|------|------------|
| **Overview** | Next event + quick actions |
| **Events** | Internal (members-only) vs campus/public lists |
| **Members** | Roster — On Ligo / Invited / Not on Ligo |
| **Invite members** | Get people *onto Ligo*, then into the org — **not** a party guest list |
| **Create / + Create** | Publish a new event |

## Suggested walkthrough ( ~3 minutes )

Do it in this order so the story clicks:

1. **Pass / I’m In** — clear 1–2 invite cards (I’m In on one so it shows in My Events).
2. **Explore** — open a campus event, look around, optionally RSVP.
3. **My Events** — confirm the thing you said I’m In to is there.
4. **Clubs → GPB** — peek Chat / Events / People. Optional: **Open event ops**.
5. **Manage**
   - **Invite members** — run the invite-to-app flow once.
   - **+ Create → Autofill Kickoff → Members Only → Publish**  
     Then open **Group chat** + **Send update** on that event.
   - **+ Create → Autofill Breakfast → Georgetown → Publish**  
     Then flip to **Explore** — Breakfast should be on the campus feed.

**The point:**  
Kickoff (members-only) stays inside the club.  
Breakfast (campus) hits Explore.  
Same admin tool, two distribution modes.
